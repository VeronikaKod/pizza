# pizza
Программа для пиццерии
Уважаемый, смотри, мяу
открываешь вкладочку pizza.zip, справа увидишь кнопку "Исходный код", смотри еще правее и нажимай на значек загрузки(эт такая стрелочка вниз, а под ней тарелочка)
Подождали загрузку, открыли загруженный файл справа сверху
Открывай файл pizza, дальше dist, дальше pizza, кнопка ИЗВЛЕЧЬ ВСЕ, извлечь, ждешь загрузку (если выпадет предупреждение от ВИНДОУС, нажми строчку "подробнее" и появится новая кнопка "открыть принудительно")
Дальше снова открываем pizza, далее dist, открывавем файл pizza (если выпадет предупреждение от ВИНДОУС, нажми строчку "подробнее" и появится новая кнопка "выполнить в любом случае")
Открывается приложение, пользуемся на здоровье, ставьте лайки, пишите комментарии, подписывайтесь на канал, обнимите маму
